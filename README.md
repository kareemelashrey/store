# Kareem Accounting

برنامج حسابات للمحلات بالعربي: مخزون، عملاء، فواتير، مشتريات، خزينة، محافظ، شيكات، موظفين، شركاء، وتقارير.

## التشغيل
- الواجهة: ملف `index.html` واحد (يتشغّل من أي استضافة ثابتة مثل GitHub Pages).
- قاعدة البيانات: Supabase. الحماية بتتحكم فيها سياسات RLS والدوال.

## الأدوار
- **مدير**: كل الصفحات والإعدادات والمستخدمين.
- **مشرف**: الصفحات المفتوحة له من الإعدادات، وعملياته حسب صلاحياته من صفحة المستخدمين.
- **كاشير**: البيع وفواتير النهاردة بس.

## الإعدادات (للمدير)
- تشغيل وإيقاف الصفحات.
- صلاحيات المشرف على الصفحات.
- الألوان (محفوظة في قاعدة البيانات، بتتطبق على كل الأجهزة).
- الدعم الفني: التذاكر بتيجي للمدير من زرار 🆘 في الشريط العلوي.

## النسخة الاحتياطية
- من صفحة **النسخة الاحتياطية**. الملف مشفّر بكلمة سر (AES-256).
- **كلمة السر مش بتتسترجع.** لو نسيتها، الملف مش هيتفتح.
- الاسترجاع بيستبدل كل البيانات الحالية، وقبله بيتعمل نسخة أمان تلقائياً.
- احفظ النسخ بره الجهاز.

## الترخيص
- جميع الحقوق محفوظة لصاحب المحل المرخّص له. يُسجّل مفتاح الترخيص من **الإعدادات**.

## قبل أي تحديث
1. خد نسخة احتياطية مشفّرة.
2. جرّب التحديث على نسخة تجريبية من Supabase.
3. شغّل ملفات SQL بالترتيب.
